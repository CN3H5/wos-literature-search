# wos-literature-search

用于 Web of Science（WoS）论文检索与精读的 Codex 技能：先筛选主题相关的论文，再比较引用影响与时效性，获取合法全文，并基于实际阅读内容总结方法、结果和局限。

适合快速建立重点论文清单、了解某个方向的代表性工作或寻找近期进展。它提供检索和阅读流程，实际访问依赖运行环境提供的工具及用户已有权限。

## 主要能力

- **相关性优先**：先查看相关性排序，再比较同一结果集的引用次数和发表日期；记录实际查看的论文范围。
- **引用口径明确**：区分 Core Collection、All Databases 和其他来源的计数，记录统计日期；未取得归一化指标时明确说明。
- **筛选过程可追溯**：保留检索式、日期和语言条件、数据库范围、筛选数量与排除理由。
- **按研究类型阅读**：分别处理实证、综述、定性和理论研究，提取适用的方法、证据与局限。
- **版本与状态核查**：核对论文身份、阅读版本、更正、撤稿或关注声明，注明核查来源与日期。
- **访问失败有交接方案**：支持使用用户提供的 WoS 导出文件，并说明离线数据范围和缺失信息。

## 环境与安装

使用前需要：

1. 能够加载此技能的 Codex 环境。
2. 可用的 WoS 工具或受支持的浏览器，以及所需的个人或机构访问权限；也可以提供已有的 WoS 导出文件。
3. 按任务需要，提供网页阅读、文件下载或 PDF 阅读能力。

本仓库包含技能说明与辅助文档，不附带 WoS 连接器、浏览器驱动、账号或订阅权限。

### 使用技能安装器

在支持 `$skill-installer` 的 Codex 环境中输入：

```text
$skill-installer 从 https://github.com/CN3H5/wos-literature-search
安装技能。技能位于仓库根目录，名称为 wos-literature-search。
```

私有仓库需要已授权的 GitHub 访问方式。不要把访问令牌、密码或 Cookie 写入提示词、仓库地址或技能文件。

### 作为项目技能使用

在目标项目根目录执行以下命令，需要已安装 Git 并具备仓库访问权限：

```sh
git clone https://github.com/CN3H5/wos-literature-search.git .agents/skills/wos-literature-search
```

也可以将完整技能目录放入当前环境支持的技能位置，保留目录结构。安装后确认技能列表中出现 `wos-literature-search`；如果没有出现，重启 Codex 后再检查。技能发现与安装方式参见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 使用示例

安装后，在对话中显式调用 `$wos-literature-search`，并说明研究主题、时间范围、论文数量和阅读要求。

### 兼顾引用影响与时效性

```text
使用 $wos-literature-search 检索近三年关于大语言模型推荐系统的论文。
近三年按检索日向前滚动三年计算。挑选 2 篇兼顾引用影响与时效性的论文，
获取合法全文，总结研究问题、方法、主要结果和局限，
并给出引用口径、统计日期、阅读版本及阅读范围。
```

### 设置硬性引用门槛

```text
使用 $wos-literature-search 检索 2024—2026 年关于数字阅读的实证研究。
筛选 5 篇 Core Collection 被引次数至少 40 次的论文，排除综述。
如果满足条件的论文不足 5 篇，请说明缺口，不要降低门槛。
```

### 使用已有导出文件

```text
使用 $wos-literature-search 分析我提供的 WoS 导出文件，选出最相关的 3 篇论文。
本次没有实时 WoS 访问权限，请仅对导出记录进行排序和筛选，
注明导出范围、引用统计时间及缺失字段，再尝试获取合法全文。
```

还可以补充排除主题、文献类型、检索和筛选语言、机构入口，以及是否需要保存 PDF。遇到登录或验证码时，由用户在原页面完成操作，技能不收集登录凭据。

## 默认规则

明确提出的要求优先于下列默认设置。

| 项目 | 默认处理 |
|---|---|
| 论文数量 | 5 篇 |
| 时间范围 | 当前年及之前 4 个日历年，运行时说明确切边界 |
| 日期依据 | 通常采用正式发表日期，区分预印本、早期访问和修订日期 |
| 数据库 | 优先 WoS Core Collection，记录实际可用的索引和版本 |
| 排序策略 | 先相关性，再比较引用与日期；不可用的排序会如实说明 |
| 文献类型与语言 | 不擅自限定期刊或原创研究；分别说明检索词语言与语言过滤条件 |
| 引用与近期论文的搭配 | 默认 5 篇时，可从约 3 篇已有引用积累和 2 篇最近两个日历年论文开始考虑；按实际候选调整 |

主题相关性和用户条件是入选前提。较高引用次数不能弥补主题不符，也不会为填满近期论文名额而降低硬性引用门槛。

“高被引”需要结合领域、发表年限和文献类型解释；引用次数本身不证明研究质量。没有可核验的归一化指标时，结果会标注 `raw count, not field-normalized`。

## 输出内容

最终报告根据任务需要提供：

| 部分 | 内容 |
|---|---|
| 检索说明 | 检索式、检索语言、数据库与索引、有效过滤条件、日期及命中数 |
| 筛选记录 | 实际查看的排序视图、记录范围与数量、排除理由及覆盖限制 |
| 论文清单 | 标题、作者、正式年份、类型、DOI 或 WoS ID、选择理由 |
| 引用证据 | 原始引用次数、指标名称、统计范围与日期，以及可用的归一化指标或官方标识 |
| 全文与版本 | 出版社或仓储链接、阅读版本、访问与许可信息、所需的本地文件链接 |
| 阅读与总结 | 阅读范围、研究问题、方法、结果、适用的证据定位及局限 |
| 发表状态 | 更正、撤稿或关注声明的核查结果、来源与日期；未检查时明确标注 |

阅读状态区分元数据、摘要、选定全文章节和整篇论文。获取全文不等于已经通读，摘要证据也不会被表述为全文阅读结果。

## 访问、隐私与使用边界

- 无实时 WoS 访问时，可筛选用户提供的导出记录；没有访问权限也没有导出文件时，提供人工检索和导出指引，并说明无法继续的步骤。
- 通过出版社、仓储或授权机构入口获取全文，不绕过付费墙、登录、会话限制或 DRM。
- 不保存凭据或会话令牌，不擅自把全文上传到额外服务。工作文件留在任务工作区，保留用户要求的交付文件。
- 查询内容会传给实际使用的检索服务。若研究主题或机构入口涉及保密信息，应在检索及分享报告前检查相应内容。
- 公开可访问不代表具有再分发许可；下载论文的使用仍受其许可条款约束。

此技能用于快速重点论文筛选，不提供穷尽检索或完整系统综述流程。检索覆盖、全文可得性和发表状态核查取决于实际权限与工具；未知信息会保留为未知。历史页面观察不保证当前界面的行为。
